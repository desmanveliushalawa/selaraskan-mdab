## Analisis Validitas Temuan & Tindakan Perbaikan

### HIGH (Hard Gate Violations)

---

**F-01** | R-26 | **Interactive element: "Lihat Komparasi Before-After" di Tab 2 tidak trigger dialog**
- **Analisis:** **BENAR (VALID BUG)**.
- **Penyebab:** Pada implementasi sebelumnya, `uploaded_file.read()` dipakai berulang pada rerun sehingga pointer berada di EOF (`b""`). Selain itu, tanpa caching, proses parsing PDF dijalankan ulang setiap kali tombol diklik sehingga state Streamlit bergeser dan dialog tertutup/tidak sempat terbuka.
- **Tindakan Perbaikan:**
  1. Mengganti `uploaded_file.read()` menjadi `uploaded_file.getvalue()`.
  2. Menambahkan `st.session_state["parsed_cache"]` untuk mengunci hasil ekstraksi sehingga tidak re-parse berulang saat klik tombol dialog.
- **Status:** SELESAI DIPERBAIKI.

---

**F-02** | R-25 | **Contrast potensial: `#64748b` di atas `#f8fafc`**
- **Analisis:** **SEBAGIAN SALAH DARI SISI HITUNGAN (BANTAHAN), TETAPI TINDAKAN PERBAIKAN DITERIMA.**
- **Bantahan Matematis:** Perhitungan formula WCAG AA menunjukkan `#64748b` pada `#f8fafc` menghasilkan rasio kontras `4.55:1`. Ambang batas WCAG AA normal text adalah `4.5:1`, sehingga secara matematis sebenarnya lolos tipis (margin 0.05).
- **Tindakan Perbaikan:** Demi kejelasan visual teks kecil (11px-12px) pada berbagai tipe monitor, warna teks sekunder diganti menjadi `#475569` (Slate-600) dengan rasio kontras `7.24:1` (Lolos WCAG AAA untuk large text dan AA solid untuk normal text).
- **Status:** SELESAI DIPERBAIKI.

---

**F-03** | R-27 | **Tab 3 (Manajemen Bucket) tidak punya error state pada proses tambah dokumen**
- **Analisis:** **BENAR (VALID)**.
- **Penyebab:** Tombol "Ekstrak & Tambahkan ke Bucket" dan "Buat Bucket Baru" sebelumnya tidak memiliki blok `try...except`.
- **Tindakan Perbaikan:** Menambahkan penanganan `try...except Exception as e: st.error(...)` pada kedua aksi di Tab 3.
- **Status:** SELESAI DIPERBAIKI.

---

**F-04** | R-35 | **Tidak ada click-through evidence yang tercatat per elemen**
- **Analisis:** **BENAR (VALID SECARA STANDAR AUDIT)**.
- **Tindakan Perbaikan:** Menyediakan daftar bukti uji interaksi elemen per elemen (*click-through verification evidence*) pada laporan penyelesaian kerja.
- **Status:** SELESAI DIVERIFIKASI.

---

**F-05** | R-39 | **Tidak ada `cursor: pointer` di CSS untuk hover card**
- **Analisis:** **BENAR (VALID)**.
- **Tindakan Perbaikan:** Menambahkan aturan CSS global `button, select, [role="button"], a { cursor: pointer !important; }` pada blok style utama.
- **Status:** SELESAI DIPERBAIKI.

---

**F-06** | R-39 | **Tidak ada `lang` attribute pada HTML output**
- **Analisis:** **SEBAGIAN SALAH DARI SISI SIFAT RUNTIME STREAMLIT (BANTAHAN), TETAPI BISA DIATASI.**
- **Bantahan:** Streamlit mengontrol root shell HTML di level server React, sehingga pengembang Python tidak memiliki direct handle ke tag `<html>`.
- **Tindakan Perbaikan:** Menginjeksikan `<script>document.documentElement.lang = "id";</script>` pada layer rendering atas sehingga tag `<html>` secara dinamis tersetel ke Bahasa Indonesia di peramban.
- **Status:** SELESAI DIPERBAIKI.

### MEDIUM (Purpose-Gate : Teknik Dipakai Tanpa Alasan Tertulis)

---

**F-07** | R-14 | **Semua bucket card memiliki struktur dan ukuran identik**
- **Analisis:** **SEBAGIAN SALAH DARI SISI KEBUTUHAN DATA PERBANKAN (BANTAHAN), TETAPI HIERARKI PERLU DIPERTEGAS.**
- **Bantahan:** Bucket merepresentasikan entitas repositori data setara (seperti master data rekening/berkas). Ukuran acak justru merusak keterbacaan data resmi.
- **Tindakan Perbaikan:** Menambahkan pembeda visual hierarkis yang tegas: kelas `.bucket-default` (garis aksen kiri navy tebal `#003d79`) untuk korpus bawaan regulator vs kelas `.bucket-custom` (garis aksen biru `#2563eb`) untuk koleksi pengguna.
- **Status:** SELESAI DIPERBAIKI.

---

- **Tindakan Perbaikan:** Menambahkan komentar dokumentasi R-09 pada baris pembuatan badge di Tab 3, menerangkan bahwa badge tersebut fungsional untuk mengontrol izin tombol hapus.
- **Status:** SELESAI DIPERBAIKI.
